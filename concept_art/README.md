# Concept art

Reference art only. Godot ignores this whole folder (`.gdignore`); game-ready models go in `assets/models/` as .glb.

| Folder | What goes in it |
|---|---|
| `world/` | The world and its mood: realms (Asgard, Midgard, Helheim), healthy vs sinking land, island/map concepts, the Blender island |
| `terrain/` | Ground textures, hex tiles, hills, mountains and peaks, trees and grass |
| `rifts/` | Rifts, the void, Yggdrasil's roots |
| `characters/skoll/` | Sköll: concept sheets, Meshy models, the rigged version, in-game previews |
| `characters/sunna/` | Sunna (the Sun's Daughter): concepts and models |
| `characters/warriors/` | Army units and warriors |
| `creatures/` | The brood, chaos warbands, root monsters and other beasts |
| `buildings_and_props/` | Longhouses, outposts, ruins, runestones, boulders |
| `ui/` | UI concepts and UI pieces (`ui_assets/`) |
| `screenshots/` | Screenshots of the game itself (v12, v13... are 3D view versions) |
| `videos/` | Gameplay clips and generated videos |
| `heyoz_experiments/` | Video experiments (the first trailer uses these; left in place) |

Big source files (.blend, .blend1, .mp4, .gif, .zip) stay on your PC only: .gitignore keeps them out of git in every subfolder.
